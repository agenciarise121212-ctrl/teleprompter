# TP RISE - Professional Teleprompter Studio

Aplicativo web profissional de teleprompter desenvolvido sob medida para a **Agência RISE**.

## Como publicar no GitHub Pages (Gratuito):

1. Crie um novo repositório público no GitHub chamado `tp-rise`.
2. Baixe e extraia o arquivo ZIP fornecido.
3. Arraste e solte o arquivo `index.html` diretamente na raiz do seu repositório do GitHub.
4. Clique em **Commit changes**.
5. No seu repositório, acesse **Settings** > **Pages**.
6. Em **Build and deployment**, selecione `Deploy from a branch`, escolha a branch `main` e clique em **Save**.
7. Pronto! O GitHub fornecerá seu link em instantes (ex: `https://seu-usuario.github.io/tp-rise`) para uso em qualquer celular, tablet ou monitor de estúdio.
