# TP RISE - Teleprompter Pro

Este é o aplicativo de teleprompter inteligente criado especialmente para a Agência RISE.

## Como hospedar no GitHub Pages de forma gratuita:

1. Acesse o seu GitHub (github.com).
2. Crie um novo repositório chamado `tp-rise` (ou o nome que preferir) e deixe-o como Público.
3. Extraia este arquivo ZIP.
4. Arraste e solte o arquivo `index.html` (e outros arquivos, se houver) diretamente para dentro do seu novo repositório no GitHub.
5. Clique no botão verde "Commit changes" para salvar o arquivo lá.
6. No seu repositório, clique na aba **Settings** (Configurações).
7. No menu lateral esquerdo, clique em **Pages**.
8. Na seção "Build and deployment", em "Source", selecione "Deploy from a branch".
9. Logo abaixo, em "Branch", selecione `main` e clique em **Save**.
10. Aguarde de 1 a 2 minutos e recarregue a página. O GitHub fornecerá um link (ex: `https://seunome.github.io/tp-rise`) que você pode acessar de qualquer celular, tablet ou computador para usar o teleprompter!
