# TP RISE - Teleprompter Mágico & Profissional

O **TP RISE** é um aplicativo web de teleprompter de alta performance desenvolvido especialmente para criadores de conteúdo, gravadores de vídeos, palestrantes e profissionais que utilizam celulares ou tablets. 

Ele foi otimizado para rodar em tela cheia (estilo PWA), sem barras de rolagem indesejadas, sem zoom acidental e com controle total de velocidade e áudio.

---

## 🚀 Principais Funcionalidades

- **Início Suave:** O texto aparece de forma fluida logo no carregamento, eliminando telas pretas ou atrasos visuais.
- **Leitor Inteligente de Tags:** Suporte completo e limpo para formatação de roteiros com marcações como `[CENA X]` e `[ÁUDIO: ...]`.
- **Modo Otimizado para Celular / PWA:** Bloqueio de zoom por pinça, prevenção de rolagem lateral e suporte para salvamento direto na tela inicial do celular.
- **Controles Dinâmicos:** Os botões de ação e reprodução aparecem e desaparecem automaticamente após 3 segundos de leitura contínua. Um simples toque na tela reativa os controles instantaneamente.
- **Espelhamento Ajustável:** Suporte a visualização normal, espelhamento vertical, horizontal ou ambos (ideal para uso com lentes beam-splitter).
- **Barra de Progresso Interativa:** Toque em qualquer ponto da barra de progresso para saltar instantaneamente para aquela parte do roteiro.

## 🛠️ Como Usar no GitHub / Publicar (GitHub Pages)

1. Crie um novo repositório no seu GitHub (ex: `tp-rise`).
2. Adicione o arquivo principal renomeado para `index.html`.
3. Adicione este arquivo `README.md` na raiz do repositório.
4. Vá em **Settings > Pages** no seu repositório do GitHub e ative o **GitHub Pages** apontando para a branch `main` (ou `master`), pasta `/ (root)`.
5. Acesse o link gerado pelo GitHub Pages diretamente no navegador do seu celular, clique nos três pontos do navegador e selecione **"Adicionar à Tela Inicial"** ou **"Instalar Aplicativo"**.

---

## 💻 Estrutura de Arquivos

O projeto utiliza a arquitetura de **Arquivo Único (Single-File App)**, unindo HTML estruturado, estilos CSS otimizados (Tailwind CSS) e lógica interativa JavaScript em um único arquivo de altíssima performance:

- `index.html` — Aplicativo completo do Teleprompter Mágico.
- `README.md` — Documentação do projeto.
